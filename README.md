# Midnight Order — Mnemonica Trainer

A standalone mobile-first web prototype for memorizing the Mnemonica stack.

Menus:
1. Stack — complete 52-card reference, with position hiding
2. Position — position → card recall
3. Card — card → position recall
4. Shift — cyclic 52-card cut calculation
5. Around — previous/current/next sequence practice

The app stores practice statistics locally in the browser via localStorage.

The stack data follows the Mnemonica.app reference page updated September 3, 2026.
